FRIENDSHIP.EXE — AUDIO FOLDER
=============================

ضع ملفات الموسيقى المحلية هنا (اللي مسموح لك تستخدمها).

Put your local, permitted audio files in this folder.

المسار في الكود:
  src/data/audioTracks.ts  ->  الحقل src

الملفات الافتراضية المتوقعة:
  night-city.mp3
  rooftop.mp3
  chill.mp3

مش لازم تكون بنفس الأسماء. أيًا كان اسم الملف، لازم تعدّل
src/data/audioTracks.ts وتخلي الحقل `src` مطابق لاسم الملف عندك، مثال:
  { id: 'night', title: 'ليل المدينة', src: 'audio/اسم-الملف-عندك.mp3' }

ملاحظات:
- لو الملفات مش موجودة، المشغّل هيقول "الملف الصوتي غير متاح"
  من غير ما يستسلم أو يعطّل باقي الموقع.
- مفيش تشغيل تلقائي للصوت. التشغيل يبدأ فقط بعد تفاعل منك.
- الامتدادات المدعومة عادة: mp3 / ogg / wav / m4a حسب المتصفح.
